# 🔔 הקמת תזכורות בטלגרם – פעם אחת, כ-10 דקות

## שלב 1 – יצירת הבוט (בטלפון, בטלגרם)
1. מחפשים בטלגרם **@BotFather** (עם וי כחול) ולוחצים Start.
2. שולחים: `/newbot`
3. שם לבוט, למשל: `קוקו`
4. שם משתמש באנגלית שנגמר ב-bot, למשל: `KokoLife_Ofek_bot`
5. BotFather שולח **טוקן** – שורה ארוכה כמו `7712345678:AAH...`. שומרים אותה לשלב 3.

## שלב 2 – מפתח גישה ל-Firebase
1. Firebase → ⚙️ **Project settings** → לשונית **Service accounts**.
2. **Generate new private key** → **Generate key**. יורד קובץ JSON.
3. ⚠️ זה מפתח סודי – **לא** מעלים אותו ל-GitHub כקובץ, רק מדביקים בשלב הבא.

## שלב 3 – סודות ב-GitHub
ריפו KokoLife → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | הטוקן מ-BotFather |
| `FIREBASE_SA` | **כל** התוכן של קובץ ה-JSON (פותחים ב-Notepad, Ctrl+A, Ctrl+C) |

## שלב 4 – העלאת הקבצים
- את התיקייה `reminders` מעלים כרגיל (Add file → Upload files, גוררים את התיקייה).
- את קובץ ה-workflow יוצרים ידנית: **Add file → Create new file**, בשם כותבים בדיוק:
  `.github/workflows/reminders.yml`
  ומדביקים את התוכן של הקובץ `.github/workflows/reminders.yml` מה-zip → **Commit changes**.

## שלב 5 – הפעלה ראשונה
1. ריפו → לשונית **Actions** → אם מופיעה הודעה, לוחצים **I understand… enable**.
2. בצד: **Koko reminders** → **Run workflow** → **Run workflow**.
3. אחרי כדקה מופיע ✅ ירוק.

## שלב 6 – חיבור (כל אחד בטלפון שלו)
1. באפליקציה: מסך הבית → **🔔 תזכורות בטלגרם** → **חיבור הטלגרם שלי** → בטלגרם לוחצים **Start**.
2. האישור "✅ מחובר" מגיע בבדיקה הבאה (עד שעה). רוצים מיד? מריצים שוב **Run workflow** – וגם תגיע הודעת בדיקה עם כל מה שב-30 הימים הקרובים.

## איך זה עובד
- GitHub מריץ בדיקה כל שעה. מ-11:00 (שעון ישראל) נשלחת פעם ביום הודעה על מה שנשאר לו **שבוע** או **יום**: טיפולים וחיסונים, מסמכים שפג תוקפם, ואוכל שעומד להיגמר.
- אם אין כלום – לא נשלחת הודעה.
- GitHub לפעמים מאחר בכמה דקות, אז ההודעה יכולה להגיע ב-11:20–11:40.
- להפסקה: שולחים לבוט `/stop`.
